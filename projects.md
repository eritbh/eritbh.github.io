I don't do much coding in public under this name anymore, but I still try to maintain a couple silly things:

- A personal set of [user styles](/userstyles) which I've generalized enough to be useful to others
- A set of [titlebar themes for KDE Plasma](https://github.com/eritbh/kde-application-titlebar-themes) for matching with specific application coloe schemes

I previously maintained a bunch of stuff related to Reddit moderation and community management:

- [Toolbox for Reddit](https://github.com/toolbox-team/reddit-moderator-toolbox), a browser extension for Reddit moderators which a lot of people used (and some probably still do!) but is increasingly being obviated by changes made to the platform as a whole
- [The /r/anime subreddit theme](https://github.com/r-anime/stylesheet), which I designed myself but which doesn't really need much ongoing maintenance
- [A bunch of other miscellaneous infrastructure and administration stuff for /r/anime](https://github.com/r-anime) which has been mostly taken up by others

And some other tools that others may have used at some point but probably shouldn't anymore:

- A command framework for Discord bots, called [Yuuko](https://eritbh.me/yuuko), written for Typescript and built on [Eris](https://github.com/abalabahaha/eris) which is pretty dead now. I've stopped working on this and have been out of the Discord dev game for years at this point
- A [collection of SSH utilities for 1Password users](https://github.com/eritbh/1password-ssh-utils) which I've [blogged](/2021/01/01/storing-ssh-keys-in-1password) [about](/2022/01/25/1password-ssh-keys-improved) in the past. Nowadays the built-in SSH key management features of 1Password are good enough to do what I need

I also have several personal projects which are not at all ready for others to use:

- Some [pointless](https://github.com/eritbh/toolbox-api) [Javascript](https://github.com/eritbh/another-logger) [libraries](https://github.com/eritbh/emit-deprecation)
- A [utility](https://github.com/eritbh/rl-overlay-generator) for easily generating real-time Rocket League OBS overlays from Adobe Illustrator documents for RL streamers and esports organizations
- A couple hardware projects for [controlling LEDs via WiFi](https://github.com/eritbh/esp01-led-controller) and [experimenting with FPGAs and video capture](https://github.com/eritbh/flextest)
